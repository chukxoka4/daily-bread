# Daily Bread

A Bible reading-plan app you can install on your phone. Each day gives you an Old Testament reading, a Psalm or Proverb, and a New Testament reading, and the plan covers the whole year. You tick each section off as you read, and your progress and streak stay on your device with no account needed. A Browse tab lets you read any book and chapter with your own reader settings, and the World English Bible comes with streamed audio narration.

Live: https://daily-bread-fawn.vercel.app

## Features

- One-year plan: an Old Testament, a Psalms or Proverbs, and a New Testament reading for every day
- Progress, completed days and current streak saved in the browser
- Switch translations in one tap
- Browse any book and chapter, with reader settings
- Audio narration for the World English Bible, streamed chapter by chapter
- Installable as a PWA (web manifest and service worker)

## Stack

Next.js 16 (App Router), React 19, TypeScript and Tailwind CSS 4, deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
